# 12: iOS account settings

**What to build:** A user can choose on iOS which accounts are tracked for spending and which count in net worth, and set their share percentage for a shared account so only their share counts toward spending and net worth.

Source spec: `.scratch/ios-money-buckets/spec.md`

- [ ] Changes are saved to the server and reflected on the web, and in Home after refresh.
- [ ] Failed changes show clearly and are not shown as applied.
- [ ] Workflow tests cover each setting, share percentage, and failed update.
