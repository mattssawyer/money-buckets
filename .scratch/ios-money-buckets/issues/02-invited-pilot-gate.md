## Question

What should the invited iOS pilot demonstrate before Money Buckets proceeds to broad App Store availability? Define the product outcomes or user evidence that would make the pilot successful, using the first-release task scope settled in “What web tasks and user journeys must the first iOS release support to meet the agreed full-parity direction?”

## Answer

Use an outcome-based gate with no numeric adoption target: before broad availability, invited users should be able to complete the agreed workflows, trust the spending picture (especially how much guilt-free spending remains), and report no major usability blockers.
